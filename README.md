# 🏨 Hotel Booking System

    A comprehensive hotel booking platform developed using **PHP**, **MySQL**, and **SCSS**, offering functionalities for both users and administrators. This system facilitates room reservations, user authentication, and administrative management, providing a seamless experience for hotel operations.

---

## 🧰 Tech Stack
    
    - **Frontend**: HTML5, CSS3, SCSS, JavaScript
    - **Backend**: PHP
    - **Database**: MySQL
    - **Admin Panel**: Custom-built using PHP
    - **Authentication**: PHP Sessions

---

## 📁 Project Structure

    hotel-booking-/
    ├── admin-panel/           # Administrative dashboard and controls
    ├── auth/                  # User authentication (login, register, logout)

    ├── css/                   # Compiled CSS files

    └── README.md              # Project documentation

## 🔑 Features

### 🧑‍💼 User Panel
    
    - **User Registration & Login**: Secure authentication system.
    - **Room Browsing**: View available rooms with details.
    - **Booking System**: Reserve rooms with real-time availability checks.
    - **Profile Management**: Update personal information and view booking history.

### 🛠️ Admin Panel
    
    - **Dashboard**: Overview of bookings, users, and room statuses.
    - **Room Management**: Add, edit, or remove room listings.
    - **Booking Management**: Approve or cancel reservations.
    - **User Management**: View and manage registered users.
    - **Reports**: Generate booking and revenue reports.

## 🛠️ Installation & Setup

1. **Clone the Repository**

   ```bash
   git clone https://github.com/bhaktofmahakal/hotel-booking-.git


**Set Up the Database**

    Import the database.sql file into your MySQL server to create the necessary tables.

Configure the Database Connection

Update the database credentials in 

    config/db_config.php:

    
    define('DB_SERVER', 'localhost');
    define('DB_USERNAME', 'your_username');
    define('DB_PASSWORD', 'your_password');
    define('DB_NAME', 'hotel_booking');
    
**Run the Application**

Deploy the project on a local server (e.g., XAMPP, WAMP) or a live server.

Access the application via

     http://localhost/hotel-booking-/.
